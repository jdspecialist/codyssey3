# Mini NPU Simulator

AI가 이미지나 패턴을 인식할 때 사용하는 핵심 연산인 **MAC(Multiply-Accumulate)**을  
Python 콘솔 프로그램으로 직접 구현한 미니 시뮬레이터입니다.

## 실행 방법

```bash
python main.py
```

실행 후 모드를 선택합니다.

- `1`: 사용자 입력 모드 — 3×3 필터 A/B와 패턴을 직접 입력
- `2`: `data.json` 분석 모드 — 5×5, 13×13, 25×25 패턴 일괄 분석

`data.json`은 `main.py`와 같은 폴더에 위치해야 합니다.

## 구현 요약

### MAC 연산

MAC 연산은 입력 패턴과 필터의 같은 위치 값을 곱한 뒤, 모든 곱셈 결과를 더하는 방식입니다.

\[
score = \sum_{i=0}^{N-1}\sum_{j=0}^{N-1} pattern[i][j] \times filter[i][j]
\]

예를 들어 십자가 패턴과 십자가 필터의 점수는 5가 되고, 십자가 패턴과 X 필터의 점수는 1이 됩니다.  
따라서 점수가 더 큰 필터를 선택하여 해당 패턴을 판별합니다.

이 프로젝트에서는 NumPy 같은 외부 라이브러리를 사용하지 않고,  
`for` 반복문으로 `pattern.get(row, col) * filter.get(row, col)`을 수행한 뒤 누적했습니다.

### 라벨 정규화

`data.json`에서는 라벨이 `+`, `x`, `cross`, `X` 등 여러 형태로 쓰일 수 있습니다.  
프로그램은 이를 내부 표준 라벨인 `Cross`와 `X`로 변환합니다.

| 입력 값 | 정규화 결과 |
|---|---|
| `+`, `cross`, `Cross`, `CROSS` | `Cross` |
| `x`, `X`, `x_filter`, `X_FILTER` | `X` |

정규화를 적용하면 필터 키와 expected 라벨의 표기 차이 때문에 발생하는  
잘못된 FAIL을 방지할 수 있습니다.

### 동점 처리 정책

두 점수의 차이가 `1e-9`보다 작으면 동점으로 처리합니다.

```python
abs(score_a - score_b) < 1e-9
```

부동소수점 연산에서는 `0.9`와 `0.9000000000000001`처럼  
미세한 오차가 발생할 수 있습니다.  
따라서 단순히 `==`로 비교하면 실제로는 같은 값이라도 다른 값으로 판단될 수 있습니다.

동점인 경우 판정은 `UNDECIDED`로 출력하며,  
`expected`가 `Cross` 또는 `X`라면 `FAIL`로 처리합니다.

## 결과 리포트

### 실패 원인 분석

실패 케이스는 아래 세 가지 원인으로 구분할 수 있습니다.

1. **데이터/스키마 문제**  
   - `filters` 또는 `patterns` 키가 없는 경우  
   - 패턴의 `input`이 2차원 배열이 아닌 경우  
   - 필터 크기와 패턴 크기가 다른 경우  
   - `size_N` 키에서 N을 추출할 수 없는 경우  

2. **로직 문제**  
   - MAC 연산에서 행과 열 인덱스를 잘못 사용하는 경우  
   - Cross 필터와 X 필터를 반대로 비교하는 경우  
   - 점수 비교 방향이 잘못된 경우  

3. **수치 비교 문제**  
   - 부동소수점 오차 때문에 거의 같은 점수가 다른 점수로 처리되는 경우  
   - `epsilon`을 적용하지 않아 동점이어야 할 결과가 `Cross` 또는 `X`로 판정되는 경우  

이 프로그램은 스키마 오류나 크기 불일치가 발생해도 프로그램을 종료하지 않고,  
해당 케이스만 `FAIL`로 처리하며 실패 사유를 출력합니다.

### 실패가 0인 경우

모든 케이스가 `PASS`라면 다음 정책 덕분에 실패가 0이 됩니다.

- `+`와 `cross`는 모두 `Cross`로 정규화됩니다.
- `x`와 `X`는 모두 `X`로 정규화됩니다.
- 두 점수 차이가 `1e-9` 미만이면 동점으로 처리합니다.
- 패턴과 필터의 크기가 같은지 검증한 뒤 MAC 연산을 수행합니다.
- 오류가 있는 케이스는 프로그램 전체를 중단시키지 않고 개별 `FAIL`로 기록합니다.

### 시간 복잡도 분석

N×N 패턴과 N×N 필터의 MAC 연산은 모든 위치를 한 번씩 방문합니다.

- 행 반복: N번
- 각 행에서 열 반복: N번
- 총 곱셈 및 덧셈: N × N = N²번

따라서 시간 복잡도는 \(O(N^2)\)입니다.

| 크기 | 연산 횟수 |
|---|---:|
| 3×3 | 9 |
| 5×5 | 25 |
| 13×13 | 169 |
| 25×25 | 625 |

크기가 2배가 되면 연산 횟수는 약 4배가 됩니다.  
예를 들어 3×3은 9번, 6×6은 36번이므로 연산량은 4배 증가합니다.

성능 분석은 각 크기마다 Cross 패턴-Cross 필터, X 패턴-X 필터의 MAC 연산을  
각각 10회 수행한 뒤 평균 시간을 계산합니다.  
파일 읽기, 콘솔 출력, 패턴 생성 시간은 측정 대상에서 제외하고  
`mac_score()` 함수 호출 구간만 측정합니다.

- B 점수: 5.0
- 판정: B
